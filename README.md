## 🛠️ Tech Stack
This project is built to be lightweight, responsive, and highly maintainable:
- **HTML5** for semantic structure
- **Tailwind CSS** (via CDN) for utility-first, enterprise-grade styling
- **Lucide Icons** for clean and scalable iconography

## 🚀 How to Run Locally
Since this is a static HTML project, running it is incredibly simple:
1. Clone this repository: `git clone https://github.com/hafizhahdeaa/my_portfolio.git`
2. Open the project folder.
3. Simply double-click the `index.html` file to open it in your default web browser.
